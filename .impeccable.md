# Design Context: MDmaster

**Audience**: Irshad, a consultant who writes client deliverables, notes, and drafts in
markdown all day. Single user, macOS, often writing for an hour at a stretch.

**Use cases**: open a .md, write or edit prose, save. Occasionally export to PDF/HTML/DOCX.
Quick notes and long-form drafts alike. Replaces TextEdit.

**Tone**: quiet, warm, modern. A sheet of good paper, not a developer tool. Think iA Writer
and Bear, not VS Code. Nothing competes with the text. The interface mostly disappears.

**Aesthetic direction**: refined minimal. Warm cream paper and warm near-black ink in light
mode, warm charcoal and bone in dark mode. One accent, a muted terracotta, used only for
things you interact with (caret, selection, links, list bullets, checkboxes). Chrome is
allowed where it earns its place: a native macOS toolbar and sidebars, but they stay quiet
(system materials, SF Symbols, no custom colours except the terracotta accent on active
states). Writing Mode still hides everything. Syntax markers fade, content stands.

**Typography**: SF Pro (user chose system sans for modernity), 17pt body, generous
leading, ~680pt measure centered. Headings same family, heavier, tight tracking. SF Mono
for code.

**Differentiator**: it feels like TextEdit with taste. Open, type, done. Markdown is
visible but unobtrusive.
